# Upstream foundation

Product Home is based on the MIT-licensed
[`Telegram-Mini-Apps/reactjs-template`](https://github.com/Telegram-Mini-Apps/reactjs-template)
at commit `15519a0b284de5e70bdcfd7debbff64d215db7a5`.

The production application keeps React, TypeScript, Vite, `@tma.js/sdk-react`
and Telegram UI. The template's TON Connect, demo pages, GitHub Pages deploy,
production Telegram mocks and Eruda integration are intentionally not included.
